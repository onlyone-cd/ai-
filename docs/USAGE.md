# HireInsight — 使用文档

> 本文档面向系统的日常使用人员：招聘官、HR、部门经理、管理员。

---

## 1. 登录与首页

访问部署地址，输入用户名和密码登录。首页顶部导航栏区分所有功能模块：

- **人才库**：外部候选人管理
- **岗位管理**：招聘岗位和内部岗位
- **流程看板**：候选人流程追踪
- **面试管理**：面试安排与 AI 面试
- **Offer 管理**：Offer 创建与流转
- **BOSS 直聘**：BOSS 集成与同步
- **组织与内部人才**：组织架构与员工档案
- **AI Agent**：智能对话助手
- **后台任务**：异步任务队列
- **BI 看板**：数据统计概览
- **系统设置**：AI 配置、匹配权重、通知、用户管理

---

## 2. 外部招聘流程

### 2.1 简历导入

**方式一：直接上传**
1. 进入「人才库」，点击「上传简历」
2. 支持 TXT/MD/DOCX/PDF/ZIP 格式
3. 系统自动解析姓名、手机、邮箱、工作经验、技能标签

**方式二：BOSS 直聘插件**
1. 进入「BOSS 直聘」页面，下载浏览器插件
2. 在 Chrome 中安装插件，配置系统地址和 Token
3. 打开 BOSS 直聘网页，使用插件采集：
   - **在线简历采集**：自动遍历沟通列表，逐个打开在线简历
   - **已获取简历导入**：从已获取简历列表导入
   - **附件简历上传**：下载并解析附件简历
4. 同步任务状态可在「BOSS 直聘」页面底部查看

### 2.2 岗位匹配

1. 进入「岗位管理」，创建或编辑岗位
2. 填写岗位名称、城市、JD 描述、技能标签及权重
3. 点击「AI 生成 JD」自动生成，或「AI 校准 JD」优化
4. 点击「执行匹配」系统自动运行：
   - **规则匹配**：基于标签命中率和权重计算分数
   - **AI 复核**：DeepSeek 阅读完整简历 + JD，给出匹配理由和证据链
5. 匹配结果在「候选人」页面可查看，支持「查看简历」「加入流程」

### 2.3 流程管理

1. 从匹配结果或候选人详情点击「加入流程」
2. 流程阶段：待处理 → AI 初筛 → 业务复核 → 一面 → 二面 → 终面 → Offer → 入职
3. 在「流程看板」拖拽或点击「移动阶段」操作
4. 每个阶段变更保留历史记录（可在流程历史中查看）

### 2.4 AI 面试

1. 在「面试管理」创建面试安排（选择候选人、岗位、面试官、时间）
2. 点击「AI 生成面试计划」自动生成面试问题和评分标准
3. 点击「生成面试间链接」获得可分享的面试链接
4. 候选人打开面试即可进行 AI 面试（支持语音输入）
5. 面试完成后自动生成面试报告

### 2.5 Offer 管理

1. 候选人进入 Offer 阶段后，在「Offer 管理」创建 Offer
2. 填写薪资范围、城市、预计入职日期
3. 导出 Offer 确认函
4. 状态流转：草稿 → 已发送 → 已接受/已拒绝/已取消

### 2.6 候选人转内部员工

招聘入职的候选人可一键转为内部员工：
1. 在候选人详情页点击「转内部员工」
2. 选择组织架构、岗位、薪资信息
3. 系统自动建立员工档案并关联原候选人，不重复创建简历

## 3. 内部人才管理

### 3.1 组织架构导入

1. 进入「组织与内部人才」
2. 点击「导入组织架构」，上传 Excel 文件
3. 系统自动创建组织树（支持按上级组织折叠展开）
4. 可手动增删改查组织单元

### 3.2 员工信息导入

1. 在「组织与内部人才」点击「导入员工」
2. 上传包含员工姓名、部门、岗位、薪资、出生日期、毕业院校等信息的 Excel
3. 系统自动创建员工档案，补充缺失的字段
4. 支持单独上传员工简历（PDF/DOCX）并解析识别标签

### 3.3 员工 AI 分析

每个员工档案页面支持：

- **当前岗位分析**：AI 分析员工简历与当前岗位 JD 的匹配度，给出评分和建议
- **调岗推荐**：AI 扫描全公司岗位，推荐最适合该员工的岗位
- **离职替补推荐**：AI 从人才库中推荐最匹配的候选人替补
- **薪资合理性分析**：分析员工薪资是否合理

### 3.4 批量分析

支持按组织单元一键批量分析所有员工：
1. 进入组织单元详情
2. 点击「批量分析」
3. 系统自动为每个员工运行当前岗位分析、调岗推荐、薪资分析
4. 结果可在组织概览中查看（平均匹配分、薪资风险人数等）

## 4. BOSS 直聘集成

### 4.1 首次设置

1. 进入「BOSS 直聘」页面
2. 下载并安装浏览器插件
3. 复制系统 Token，在插件弹窗中配置
4. 在插件中填写当前 HireInsight 的正式 HTTPS 地址；不要使用裸 IP 或 HTTP 生产地址

### 4.2 简历采集

插件支持三种采集模式：

- **当前页面采集**：采集当前打开的 BOSS 简历页面
- **沟通列表采集**：自动遍历沟通列表，逐个打开在线简历采集
- **已获取简历导入**：从已获取简历列表批量导入（含附件简历）

### 4.3 话术草稿管理

1. 系统自动为匹配的候选人生成 BOSS 沟通话术
2. 在「BOSS 直聘」页面可查看、编辑、审批草稿
3. 草稿通过后标记已发送，系统记录发送状态

## 5. AI Agent 使用

### 5.1 基本对话

进入「AI Agent」页面，可以直接用自然语言提问：

- "人才库有多少人？"
- "统计一下软件开发岗位的候选人"
- "帮我创建一个 Java 后端岗位"
- "推荐 Java 岗位的候选人"
- "查看王成都的职位"
- "分析一下张三的简历"

### 5.2 Agent 能力范围

Agent 可以：
- 查询人才库和员工的统计数据
- 创建和推荐岗位
- 匹配候选人并解释匹配原因
- 查看面试/流程/Offer/BOSS 状态
- 分析员工简历并推荐调岗/替补
- 比较多个候选人
- 联网搜索（需要时自动判断）
- 执行后台任务

### 5.3 对话历史

Agent 保留对话历史，支持上下文追问。每个对话会话可独立管理。

## 6. 后台任务

异步任务包括：
- 简历重新解析（`resume_retry_parse`）
- 岗位匹配（`job_match`）
- 全量匹配校准（`matching_recalibration`）
- 备份导出（`backup_export`）
- 员工分析/调岗/替补（`employee_analyze/transfer/replacement`）

在「后台任务」页面可查看任务状态、重试失败任务、查看任务详情。

---

## 7. BI 看板

BI 页面展示：
- 候选人总数、本月新增、各经验段分布
- 岗位总数、在招岗位、各职能分布
- 员工总数、活跃/离职分析
- 流程看板各阶段候选人数量
- 面试次数、Offer 数量
- LLM 调用量统计

---

## 8. 标签质量治理

在「后台任务」页面底部的标签质量面板：
- 查看所有缺失证据、低置信度、疑似误判的标签
- 支持一键重新解析、删除、人工确认
- 搜索特定候选人或标签
- 批量操作选择

---

## 9. 常见操作示例

| 场景 | 操作路径 |
|------|---------|
| 导入候选人简历 | 人才库 → 上传简历 / BOSS 直聘 → 插件采集 |
| 创建招聘岗位 | 岗位管理 → 新建岗位 → 填写 JD → AI 生成 |
| 匹配候选人 | 岗位管理 → 岗位详情 → 执行匹配 |
| 安排面试 | 面试管理 → 创建面试 → AI 生成计划 → 生成面试间 |
| 发送 Offer | Offer 管理 → 创建 Offer → 填写信息 → 导出确认函 |
| 员工调岗分析 | 组织与内部人才 → 员工详情 → 调岗推荐 |
| 查看数据统计 | BI 看板 |
| 批量重试失败任务 | 后台任务 → 选择失败任务 → 批量重试 |
| 修改 AI 权重 | 系统设置 → 匹配权重 → 自动配置 |
| 测试 AI 连接 | 系统设置 → AI 配置 → 测试连接 |
